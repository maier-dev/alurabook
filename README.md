# 📚 AluraBook

Projeto de uma landing page de livraria online desenvolvida durante os cursos da Alura, focada em práticas modernas de **Web Design Responsivo**.

## 🚀 Tecnologias Utilizadas
* **HTML5** (Semântico)
* **CSS3** (Flexbox e CSS Grid)
* **Mobile-First Design** (Adaptado para todos os dispositivos)
* **Swiper.js** (Para componentes de carrossel)

## 🌐 Demonstração
Você pode visualizar o projeto online aqui: [Link do AluraBook](https://maier-dev.github.io/alurabook/)

## 🛠️ O que eu aprendi
Neste projeto, apliquei conceitos avançados de posicionamento com **Flexbox** e **Grid**, garantindo que a interface fosse fluida desde telas pequenas até monitores desktop. Também foquei na organização do CSS seguindo boas práticas de arquitetura.
